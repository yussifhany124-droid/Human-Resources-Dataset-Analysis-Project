# Human Resources Dataset Analysis

An end-to-end HR analytics project using Power BI. It covers data cleaning and preprocessing, defining key business questions for decision-makers (e.g., how employee age relates to satisfaction), building an interactive dashboard to answer them, and presenting the findings in a final report and presentation.
